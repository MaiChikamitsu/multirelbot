# Googleフォーム版（文字）

## 今回の実行

`questionnaire/private/google_forms/create_text_forms.gs` は2つの原稿を含む貼り付け用スクリプトです。原稿を含むためGit管理しません。

1. https://script.google.com/ で「新しいプロジェクト」を作る。
2. コード.gsの内容を上記ファイル全文に置き換え、保存する。
3. 関数一覧から `createMuzintouForm` を選んで実行する。Googleフォーム・スプレッドシートの作成許可は本人が確認して許可する。
4. 同じように `createAiForm` を実行する。実行ログにフォームの編集URLと回答保存先が出る。
5. 編集URLで原稿・前ページへの移動・小数入力・保存先を確認し、必要ならプレビューでテスト回答する。テスト回答は本番とは別途扱う。
6. Googleフォームの「公開」で回答者のアクセス範囲を確認してから公開する。組織アカウントでは外部回答者への公開が制限される場合がある。
7. 回答用URLを配布する。編集URL・回答スプレッドシートのURLは配布しない。

無人島41区間、AI23区間。それぞれ回答者ID（数字）とテーマ、3発話ごとの3ペアの必須記述欄、最後に任意の感想を含みます。値は半角-1.0〜+1.0、小数第1位まで（整数も可）。前の3発話を併記します。折りたたみ・色枠・自由なレイアウトはGoogleフォームでは再現しません。

これは専用画面とは別の収集経路です。招待コードの認証は実装していません。フォームURLと指定IDを渡して回答してもらいます。IDの重複をフォームだけでは防止しません。最終送信した回答が集計対象で、専用画面の区間ごとのDB保存とは異なります。「回答を編集」のリンクによる再編集を許可しています。

回答はGoogleフォームと紐付けたスプレッドシートに保存されます。スプレッドシートのファイル→ダウンロード→CSVで出力できます。現行専用画面のCSVとは列構成が異なり、そのまま解析へ混ぜる処理はまだ追加していません。テーマごとに別ファイルとして保持してください。

再実行ではScriptPropertiesの既存フォームIDを再利用します。同じApps Scriptプロジェクトで実行してください。途中で時間切れになった場合も同じ関数で続けられます（未公開・回答前のみ）。完成後に原稿を変更して同じ関数を実行しても既存フォームを改変しません。新しい実験は別ID・作成関数として登録します。

## 原稿更新時の生成

```sh
python3 questionnaire/google_forms/generate.py \
  --config questionnaire/private/configs/muzintou_ari_text.json \
  --config questionnaire/private/configs/ai_nashi_text.json \
  --output questionnaire/private/google_forms/create_text_forms.gs
```

ローカルのAPIモックでページ数、評定数、重複作成防止、数値形式を確認済みです。Google実サービス上での作成・権限承認・送信は未実施です。
