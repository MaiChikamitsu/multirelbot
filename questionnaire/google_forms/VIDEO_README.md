# 無人島・動画視聴版 Googleフォーム

添付PDFに記載された元フォームをコピーし、動画を別画面で一緒に視聴しながら答える版を作成します。フォーム内には動画を埋め込みません。

1. https://script.google.com/ で新しいプロジェクトを作成。
2. `create_video_form.gs` の全文を `コード.gs` に貼り付けて保存。
3. 関数 `createVideoForm` を実行。初回は自分のアカウントで権限を確認・許可。
4. 実行ログの「動画版の編集URL」を開き、プレビューを確認。
5. 編集画面から公開し、回答用URLを配布。

元フォームにアクセスできるアカウントで実行してください。Driveのコピー・Formsの編集・回答先スプレッドシートの作成を行います。Google上での実行・承認・公開は未実施です。同じプロジェクトで再実行すると、作成済みの動画版を再利用します。

## 変更内容

- タイトルの【文字版】を【動画版】へ変更。
- 「前の3発話」「今回の3発話」の見出しと会話本文を削除。
- 「現在読んだ会話まで」を「現在視聴した会話まで」へ変更（冒頭と再掲の説明）。
- ページ移動の説明を、動画停止→同じインデックスの評価→次のページ→次の区間の再生、の手順へ変更。

元フォームを直接複製するため、テーマの説明と再掲、回答者ID、テーマ、41区間×3ペアの質問、数値制限、必須設定、最後の自由記述3問、ページ構成を引き継ぎます。回答保存先は動画版専用に作成します。公開・共有範囲は編集画面で確認してください。

## 視聴

動画プレーヤーは http://127.0.0.1:8893/ （このMac上）。参加者が一緒に動画を見て、それぞれGoogleフォームに回答できます。インデックス41の後に追加の会話は再生しません。
