# 研究実験用・動画自動編集ツール

元動画の評価時刻に日本語の案内と無音を挿入するツールです。標準の起動方法を**ターミナルの質問に答える方式**に変更しました。Python 3.9.6で動作確認しています。GUI・Tkは不要です。動画はローカル処理し、元ファイルは上書きしません。

## 初回セットアップ（今のPython 3.9.6のままで使う）

1. このMacでは `edit/bin` にFFmpegとffprobeを配置済みです。Homebrewの導入は不要です。別のMacへ移す場合はCPUに適したFFmpeg・ffprobeを用意し、このフォルダへ配置するか、Homebrew導入済みなら `brew install ffmpeg` を実行してください。
2. Finderで `multirelbot/edit` を開き、**セットアップ.command** をダブルクリックします。今のPythonで `edit/.venv` を作り、そこだけにPillowをインストールします。既存のmultirelbotの環境へライブラリを入れません。Pythonの更新は不要です。
3. 完了したらEnterで閉じます。初回のライブラリ取得にはネット接続が必要です。

確実にMac付属Python 3.9.6を指定する場合は、次を実行できます。

```sh
cd /Users/kinmai/Desktop/multirelbot/edit
EDIT_PYTHON=/usr/bin/python3 ./セットアップ.command
```

macOSから確認された場合は、内容を確認したうえでFinderの右クリック→「開く」を使用してください。実行権限が失われた場合だけ `chmod +x *.command` を実行します。

## 毎回の操作

1. **起動.command** をダブルクリックします。
2. 表示されたターミナルへ、Finderから**動画ファイルをドラッグ＆ドロップ**してEnterを押します。
3. 評価時刻の一覧をまとめて貼り付けます。`1. 0:49` のような番号付きや、途中の空行もそのまま使えます。貼り付け後、最後の行でEnterを押し、**「完了」と入力してEnter**で確定します。空行だけでは確定しません（`END`でも確定できます）。

   ```text
   03:30
   07:15
   15:00
   ```

4. 案内の表示時間はEnterで10秒、変更するなら秒数を入力します。
5. 最後の評価が終了時刻と違う場合だけ、**1＝以降の会話をカット / 2＝最後の評価を元動画終了へ変更**を選択します。未入力のままでは進みません。
6. 出力先はEnterで元動画と同じフォルダです。既存ファイルがあれば自動で番号を付けた別名を提案します。変更する場合は出力MP4のフルパスを入力してください。
7. 時刻一覧と完成予想時間を確認し、Enterで作成します。`n` を入力すれば中止します。処理の進捗が％で表示され、完成すると保存先が表示されます。

処理中に中止する場合は **Control+C** を押してください。一時ファイルの片付けが終わるまで待ってください。

時刻は `M:SS`、`MM:SS` と `HH:MM:SS` に対応します。順番は自動で並べ替え、重複・不正形式・動画終了より後の時刻はエラーにします。時刻は常に元動画基準です。

GUIを利用したい場合だけ `gui.py` を使えます。標準の起動・セットアップではTkの確認・読み込みは行いません。案内画面のデザイン例は同梱PNGで確認できます。

## 実験運用

案内はGoogleドライブのプレーヤーを自動停止させる機能ではありません。視聴者が案内中に自分で一時停止し、回答後に再生します。必要なら表示時間を長くしてください。最後の案内は「これが最後の評価です。評価が終わったら、アンケートを終了してください。」となり、存在しない次番号は表示しません。

例：15分の元動画、03:30・07:15・15:00、10秒表示の場合、完成は15分30秒。案内開始は03:30・07:25・15:20です。0秒指定では会話前にインデックス1の案内が入ります。最後の時刻が0秒だけの場合、全会話のカットは認めず、終了時刻への変更を選んでください。

## 精度・対応範囲

- キーフレームで単純コピー分割せず、各会話区間を正確シークして再エンコードします。映像はH.264/yuv420p、音声は48kHzステレオAAC、MP4 faststartです。無音元動画には無音トラックを生成します。
- 評価位置は最寄りの出力フレーム境界に丸めます。29.97fps等も有理数で保持します。表示時間もフレーム数へ丸めるため、完成時間には1案内あたり最大約半フレーム、コンテナ・AACによる微小な差が出ます。
- 可変フレームレートの動画は平均fpsの固定フレームレートに変換します。フレーム補完・間引きが起こり得るため、元の全フレームの完全保持は保証しません。通常の固定fps動画を研究用途に推奨します。
- 会話の内容と順序を保ちますが、再圧縮するためビット単位の一致・無劣化ではありません。入力の先頭映像と先頭音声を使用し、他の音声・字幕・チャプターは引き継ぎません。音声はステレオに変換します。
- FFmpegの自動回転を使用し、縦動画にも対応。非正方画素は表示縦横比を維持する正方画素に変換し、H.264用に偶数サイズへ丸めます。HDR→SDRの色調整・特殊な任意角回転・破損した時間情報は対象外です。HDR動画は事前にSDRへ変換してください。
- 案内ごとにH.264映像と非圧縮PCM音声のMKV中間ファイルを作り、最後に映像を再圧縮せず結合、音声を1回だけAAC化します。AACの区間別エンコードによる境界無音を避ける構成です。一度に扱う区間は1つで、RAMに動画全体を読み込みません。
- 作業用ディスクには出力動画＋中間動画＋PCM音声の空きが必要です。PCMだけでも1時間約0.7GB、映像は内容・解像度で増えます。十分な空き容量を確保してください。正常終了・エラー・中止で一時フォルダは削除されます。OS強制終了・電源断では `.research-edit-*` が残るため、実行中でないことを確認して削除してください。
- GUIの長い処理は別スレッドで動きます。動画情報の取得とプレビュー画像生成はGUI上で実行します。

## フォントとデザインの変更

Mac標準のヒラギノ角ゴシックをPillowで画像に描画し、FFmpegで挿入するため、FFmpegの日本語描画機能に依存しません。

`editor/cards.py` の `TITLE`、`EVALUATE`、`NEXT`、`FINAL` が文章、`BACKGROUND`、`WHITE` が色、`render()` が配置・文字サイズです。幅で改行し、高さに収まるよう縮小します。プレビューと書き出しは同じ生成処理です。

別の日本語フォントを使う場合は、起動時の環境変数 `EDIT_JAPANESE_FONT` にTTF/TTC/OTFのパスを指定できます。日本語グリフを含むフォントを選び、プレビューで欠字がないことを確認してください。自動選択できなければエラーにして処理を停止します。

## ログ・トラブル対応

出力と同じ場所に「出力名.log」を残します。FFmpegコマンド、実行状況、エラーが入ります。動画は含みませんがファイルのパスは記録されます。共有する際はパスに含まれる個人情報を確認してください。

- FFmpegがない：初回手順の `brew install ffmpeg`。`ffprobe`も必要です。独自の場所なら `EDIT_FFMPEG` と `EDIT_FFPROBE` に実行ファイルの絶対パスを指定します。
- ターミナル版には `tkinter` は不要です。旧GUI版は必要な場合だけ `.venv/bin/python gui.py` で起動できますが、Mac付属Tkでの動作は保証しません。
- `No module named PIL`：セットアップ.commandを実行してください。
- 既存ログがある：失敗後も原因調査用に残します。別の出力名を使うか、確認後ログを削除してください。
- 容量不足・権限エラー：空き容量と出力先の書き込み権限を確認します。

## 開発・テスト

```sh
cd /Users/kinmai/Desktop/multirelbot/edit
.venv/bin/python -m unittest discover -s tests -v
```

単体テストは時刻の並べ替え、不正入力・重複・範囲・終了処理、通常／最終文章、横・縦画像を検証します。統合テストは4秒の赤→青動画と440Hz音声を生成し、0秒・2秒・終了への挿入、境界前後の色・音声、案内中の無音、音声位相による同期、全体時間、H.264/AAC、全デコード、元動画ハッシュ、上書き防止を検証します。無音・回転MOV・29.97fps・中止後の掃除も確認します。FFmpeg未導入時は統合テストをスキップするため、スキップがないことを確認してください。

日本語の字形と実際の視認性はプレビュー画像でも目視確認してください。実際の研究動画やGoogleドライブでの再生環境は、実験前に短いサンプルで確認してください。

## ファイル構成

```text
edit/
  cli.py                  標準の対話式ターミナル操作
  gui.py                  任意の旧GUI版
  editor/model.py         時刻の解析・編集計画
  editor/cards.py         日本語案内画像・文章・デザイン
  editor/engine.py        動画情報・FFmpeg編集・ログ・一時ファイル
  tests/test_editor.py    単体・合成動画の統合テスト
  requirements.txt        Pillow（他はPython標準ライブラリ）
  セットアップ.command    初回のみ
  起動.command            毎回の起動
```

設計時の参照：[FFmpeg公式フィルター仕様](https://ffmpeg.org/ffmpeg-filters.html)、[FFmpeg公式コマンド仕様](https://ffmpeg.org/ffmpeg.html)。

## 同梱の完成例と検証記録

`examples/編集済みサンプル.mp4` は10秒の完成例です。`動作確認結果.md` に実施環境・検証項目・限界を記載しています。通常・最終の案内プレビューPNGも同梱しています。GUI操作を含む自動確認は、画面アクセス可能なMacで `.venv/bin/python tests/gui_smoke.py` を実行できます。

## このMacのFFmpeg配置

`bin/ffmpeg` と `bin/ffprobe` に、テストで使用したFFmpeg 8.0.1（Intel Mac用、配布元 https://evermeet.cx/ffmpeg/）を配置しました。探索順は環境変数による指定、edit内のbin、PATH、Homebrewの既定位置です。このMac専用の配置で、システム全体へのインストールはしていません。

## 番号付き一覧の一括貼り付け

`会話開始：0:29` の行や `1. 0:49` 〜 `41. 14:49` の一覧を丸ごと貼り付けられます。会話開始行は参考情報として扱い、評価時点に含めず、映像もカットしません。評価時刻は元動画基準のままです。入力番号に関係なく時刻順にインデックスを割り当てます。不正時刻は無視せずエラーにします。

読み込み後に「評価時刻を41件読み込みました（00:49〜14:49）」のように表示します。最後に `完了` と入力してください。現在実行中の旧プログラムには変更が反映されないため、Control+Cで終了して `./起動.command` で起動し直します。

`examples/評価時刻サンプル.txt` はユーザー指定の41時刻の入力例です。4秒の合成動画用ではありません。
